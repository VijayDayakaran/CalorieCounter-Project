# CalorieCounter

A simple web app to track your daily calorie intake and burned calories using HTML, CSS, and JavaScript.

---

## Features

- Set a daily calorie budget
- Add food and exercise entries
- Calculates remaining calories
- Shows calorie deficit or surplus
- Clear/reset anytime

---

## Files

- `index.html` – Structure
- `counter.css` – Styling
- `counter.js` – Logic

---

## Usage

1. Open `index.html` in a browser
2. Add your budget and entries
3. Click **Calculate** to view results
